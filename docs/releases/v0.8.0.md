# Zigbee Anthema 0.8.0

The Shortcut button pushes a press at once and holds it until it is released. Its three timing settings are gone.

## What a client sees

- A press is pushed at the first Zigbee controller command that turns the group on, with no quiet time first:
  `{"press":N,…}` with the level and colour asked for so far. Commands while the press is held are part of it.
- The press is held until it is released: by the client's `POST /api/v1/button/release`, or by the touchscreen
  turning the group off. The board never releases a press by itself.
- `settle_ms`, `rearm_ms` and `off_after_s` are gone from `GET /settings`, from `PUT /settings` and from the
  state object's `settings`. A `PUT` naming one of them is refused whole, `400 bad_request` with the message
  `<key>: not a setting`, as for any key the board does not know.
- `button.release_by` and the webhook's `by` are `api` or `zigbee`, never `timeout`.
- `settled` stays, in the press and in the state's `controller`, and is always `true`: the board pushes the
  press as it stood.
- A release that could not be applied answers `503 zigbee_busy`, and the press stays held until the client
  calls again.

Nothing else on the wire changed: every URL path, every error code and every other JSON key is as before.

## Why

The client decides when a press is done. The Kohler Anthem+ integration's Button judges the release in Home
Assistant, and the touchscreen already folds quick taps into one command, so the quiet time, the re-arm window
and the board's own release had nothing left to do.

## Compatibility

- A value stored for one of the removed settings stays in the board's flash and is never read. Nothing erases
  it, and nothing needs to.
- The Kohler Anthem+ integration v0.12.0 removes the three controls. v0.11.0 shows them as unknown on a 0.8.0
  board, and a value typed into one is refused with an error message.
- A client that writes these settings should send them only to 0.7.0 and earlier; see the compatibility note at
  the end of [`docs/protocol.md`](https://github.com/frozenmartini/zigbee-anthema/blob/main/docs/protocol.md).

## Install

Use the install page, https://frozenmartini.github.io/zigbee-anthema/, or push the application image to a
board that is already running with `POST /api/v1/update` (see the README).
